# 🏛️ FORTHEPEOPLE - Government Schemes Information Portal

A comprehensive web platform providing information about various Indian Government schemes and welfare programs for citizens.

## 📋 Overview

**FORTHEPEOPLE** is a user-friendly information portal inspired by MyScheme, designed to help citizens discover, understand, and access various government schemes across different sectors. The platform simplifies the complex landscape of government welfare programs by providing clear eligibility criteria, benefits, and application guidance.

## ✨ Key Features

- **📱 Responsive Design** - Works seamlessly across desktop, tablet, and mobile devices
- **🔍 Smart Search** - Quick search functionality to find relevant schemes
- **🗂️ Categorized Schemes** - Organized by sectors for easy navigation:
  - Agriculture
  - Women Empowerment
  - Youth Employment
  - Senior Citizens
  - Healthcare
  - Banking & Financial Services
  - Housing & Shelter
  - Social Security & Welfare
  - Rural Development
  - Physically Disabled Persons
  - Employment & Promotion Schemes

- **📺 Video Guides** - Embedded YouTube tutorials explaining each scheme
- **🌐 Multi-language Support** - Google Translate integration for accessibility
- **❓ Help Section** - Comprehensive FAQ and application guidelines
- **📧 Contact Information** - Easy access to support and assistance

## 🎯 Scheme Information Provided

For each government scheme, the portal displays:
- **Establishment Year**
- **Objectives & Purpose**
- **Eligibility Criteria**
- **Benefits & Features**
- **How to Apply** (with external links to official portals)
- **Video Tutorials**

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for video content and external links

### Installation & Usage

1. Clone the repository:
```bash
git clone https://github.com/BlueLockDev/Elderly-Government-Scheme-Eligibility-Information-Portal.git
```

2. Navigate to the project directory:
```bash
cd finalproject
```

3. Open `images/front.html` in your web browser:
```bash
# On Windows
start images/front.html

# On macOS
open images/front.html

# On Linux
xdg-open images/front.html
```

**Or** use a local development server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

Then visit `http://localhost:8000/images/front.html`
